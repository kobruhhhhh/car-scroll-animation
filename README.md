# Scroll-Driven Hero Section Animation

## About

A single-section landing page where a car drives horizontally across the screen as you scroll, with a green panel revealing the headline through color contrast. Impact metric cards fade in progressively as you move through the section. Everything runs off one pinned GSAP ScrollTrigger timeline.

## Technologies Used

- Next.js
- React
- JavaScript
- Tailwind CSS
- GSAP
- GSAP ScrollTrigger

## Setup

```bash
npm install
npm run dev
```

The app will be available at:

http://localhost:3000

## Build

```bash
npm run build
npm start
```

## Features

- Scroll-controlled car animation
- GSAP ScrollTrigger integration
- Green/black text reveal effect
- Progressive impact metric reveals
- Responsive layout
- Smooth reverse scrolling
